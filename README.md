# Sezi Güngörmüş Portfolyo Sitesi

Bu klasör, yazılım mühendisliği çalışmalarımı, staj deneyimlerimi, teknik becerilerimi ve projelerimi sunduğum tek sayfa statik portfolyo sitesini içerir.

## Öne Çıkan Alanlar

- Kısa profesyonel tanıtımım
- BERT tabanlı etik mail kontrolü projem
- ASP.NET Core Razor Pages ile geliştirdiğim stok takip sistemi
- Yeteneklerim ve çalışma yaklaşımım
- CV, GitHub, LinkedIn, Kariyer ve mail bağlantılarım

## Projeler

### BERT Tabanlı Etik Mail Kontrolü

Türkçe kurumsal e-postalarda toksik, etik dışı ve ayrımcı ifadeleri tespit etmeye yönelik NLP tabanlı bir web prototipi geliştirdim. Projede Python, PyTorch, Hugging Face Transformers, FastAPI ve JavaScript kullandım.

### Stok Takip Sistemi

Kurum içi stok takibini kolaylaştırmak amacıyla web tabanlı bir stok yönetim uygulaması geliştirdim. Projede C#, ASP.NET Core Razor Pages, Entity Framework Core, SQLite ve Bootstrap kullandım.

## Kullanılan Teknolojiler

- HTML5
- CSS3
- Vanilla JavaScript
- Swiper
- Google Fonts

## Çalıştırma

`index.html` doğrudan tarayıcıda açılabilir. Carousel ve font kaynaklarının yüklenmesi için internet bağlantısı gerekir.

Yerel sunucu ile çalıştırmak için:

```powershell
python -m http.server 4173
```

Ardından tarayıcıda şu adres açılabilir:

```text
http://localhost:4173
```
