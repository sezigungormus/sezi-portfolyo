# Sezi Güngörmüş Portfolyo

Sezi Güngörmüş için hazırlanan tek sayfa statik portfolyo sitesi.

## İçerik

- Hero alanı
- Projelerim
- Yetenek Kartlarım
- Hakkımda
- İletişim placeholder bağlantıları
- Native dialog ile proje detayları
- Swiper carousel ile Stok Takip demo ekranları

## Kullanılan Teknolojiler

- HTML5
- CSS3
- Vanilla JavaScript
- Swiper CDN
- Google Fonts

## Çalıştırma

`index.html` doğrudan tarayıcıda açılabilir. CDN kaynaklarının yüklenmesi için internet bağlantısı gerekir.

Basit local server ile çalıştırmak için:

```powershell
python -m http.server 4173
```

Ardından tarayıcıda `http://localhost:4173` adresi açılabilir.
